# AI Lotto Number Recommender

**Purpose:** This application provides users with AI-powered lottery number recommendations, as well as features for checking winning numbers and viewing lottery statistics.

## Project Outline

*   **index.html:** Main application file.
*   **style.css:** Application styling.
*   **main.js:** Application logic and component definitions.

## Implemented Features
*   Separated CSS from HTML.
*   Added a simple Gemini web component (`<simple-greeting>`).
*   Pushed initial code to GitHub.
*   Added a dark mode/white mode toggle.
